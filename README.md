# Abismo

Protótipo de RPG de ação e exploração **top-down**, com combate souls-like e geração procedural de salas e biomas.

## Tecnologias

- JavaScript ES Modules
- Phaser 4.2.1
- Vite 8.3

## Executar localmente

```bash
npm install
npm run dev
```

Para gerar o build:

```bash
npm run build
```
